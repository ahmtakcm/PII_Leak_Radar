Bu klasör manuel kaynak import içindir.

Desteklenen:
- CSV
- JSON
- TXT / LOG

Kullanım:
1. _templates klasöründeki CSV şablonunu kopyala.
2. Dosyayı manual_sources_inbox içine koy.
3. py .\run_manual_import.py çalıştır.

Güvenlik / yasal not:
Bu modül yalnızca kullanıcı tarafından sağlanan veya açık/izinli kaynaklardan elde edilen kayıtları offline işler.
Yetkisiz erişim, kapalı gruba sızma, credential deneme, davet kullanımı, exploit/bypass veya illegal market işlemi yapmaz.
